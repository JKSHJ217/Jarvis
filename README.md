# JARVIS Lite — доступный прототип

Небольшой веб-прототип личного ассистента в стиле JARVIS, который можно открыть на Android и Windows.

## Что уже работает
- Чат-интерфейс.
- Озвучивание ответов средствами браузера.
- Голосовой ввод в браузерах, поддерживающих Web Speech API.
- Демонстрационные команды: время, заметки, просмотр/удаление памяти, открытие YouTube и GitHub после подтверждения.
- Память хранится локально в браузере и включается только после согласия пользователя.
- PWA-манифест и простой service worker для установки/кэширования при размещении по HTTPS.

## Ограничения
- Это не подключённая языковая модель: свободные вопросы пока не обрабатываются ИИ.
- Распознавание речи зависит от браузера и может требовать интернет.
- Веб-страница не может безопасно или произвольно управлять всеми приложениями Windows/Android. Для этого позже нужен отдельный локальный помощник с ограниченным списком разрешённых действий и явным подтверждением.
- Не храните пароли, банковские данные, API-ключи или другую секретную информацию в локальной памяти.

## Быстрый запуск
1. Распакуйте архив.
2. Для проверки можно открыть `index.html` в браузере; голосовые функции и PWA надёжнее работают на HTTPS.
3. Для установки на телефон или компьютер опубликуйте файлы на GitHub Pages или другом HTTPS-хостинге.
4. В Chrome/Edge откройте опубликованный сайт и выберите «Установить приложение», если браузер предлагает эту возможность.
